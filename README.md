# Memory Training

PAO (Person-Action-Object) trainer for the numbers 00–99.

- **Number → PAO**: see a pair, type its person / action / object.
- **PAO → Number**: see a person, action or object (or a 6-digit P·A·O story) and type the number.
- **Memorize**: configurable number of pairs, display time and wait time, then recall.

Fill in your PAO list in `pao.json`. Progress and settings are stored in the browser (localStorage).

## Lists (list.html)

Memorize 1–30 objects in order (image, name or both), then put the shuffled items back in order.
Memorize time is configurable (per item or total); the list grows by one after each perfect round.
